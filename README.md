# Awn Charity Platform

Enterprise web platform enabling humanitarian charities to assist those in need, optimize donor workflows, and track operational impact.

**Live Demo:** [awon-template.vercel.app](https://awon-template.vercel.app)

---

### Overview

Dedicated platform for charities with donor management workflows and impact tracking capabilities.

---

### Features

- Charity operations dashboard
- Donor workflow optimization
- Impact tracking
- Fully responsive design
- Modern Vuetify interface

---

### Tech Stack

- **Vue.js** · **Vuetify**
- **Firebase**
- HTML5 · CSS3 · JavaScript
- Vercel

---

### Getting Started

```bash
npm install
npm run serve
npm run build
```
